# Contributing

Изменения начинайте с теста в `tests/` и краткого описания версии `agy`, модели, схемы инструмента и фактической ошибки. Не присылайте OAuth-токены, реальные пути к секретам, дампы памяти или полные debug-логи. Новые версии npm-адаптера должны тестироваться в отдельной ветке и только затем менять закреплённую версию.

Рекомендуемый сценарий:

```bash
python -m unittest discover -s tests -v
bash -n install.sh uninstall.sh
python -m py_compile agy_manager.py scripts/patch_adapter.py
```

PR должен содержать команду воспроизведения и проверку реального изменения файловой системы. Обновления сторонних бинарных патчей анализируются отдельно. Никакие бинарники Google не коммитить.
