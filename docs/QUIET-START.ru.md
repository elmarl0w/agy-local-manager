# Тихий запуск agy (экспериментальная версия 0.1.2)

Обычная команда `agy` запускает Antigravity CLI без информационных строк `Starting proxy...`, `ready (port ...)` и повторяющегося предупреждения адаптера о непроверенной upstream-версии. Мы фильтруем только эти известные строки от Node-адаптера, не отключая общий stdout/stderr; интерфейс и ошибки должны оставаться видимыми.

Для диагностики выполните `agy doctor`, а для подробного запуска `agy --verbose`. При использовании стороннего адаптера подробные логи могут содержать чувствительные данные: прежде чем делиться ими, проверьте и удалите токены, авторизационные заголовки и личные данные.

## Порт 50998

Если порт `127.0.0.1:50998` занят, менеджер остановится до запуска нового прокси, вместо перехода на случайный порт. Это устраняет ситуацию, когда модель пропадает из списка из-за несовпадения порта. Закройте старую сессию и проверьте владельца:

```bash
ss -ltnp 'sport = :50998'
```

Не используйте `killall node`, чтобы не остановить другие приложения. После освобождения порта повторите `agy`.

## Важные ограничения

CLI и свободный адаптер сторонние. Подавленное информационное предупреждение о версии НЕ означает, что совместимость проверена авторами; это видно по `agy doctor`, документации и логам `agy --verbose`. Версия 0.1.2 тестировалась unit-тестами и проверкой синтаксиса, но не проверялась на реальном Arch Linux с запущенной Ollama.
